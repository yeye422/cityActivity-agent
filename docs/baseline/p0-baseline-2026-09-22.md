# P0 基线快照（2026-09-22）

## 固定输入

- 固定评测集：`src/main/resources/evaluation/city-dialogue-eval-set.json`
- 用例数量：35，包含单轮、多轮、时间、槽位、澄清、安全与规划场景。
- Java：OpenJDK 21.0.12。
- 配置合同：九维 `SlotBundle`、独立 `TimeConstraint`、`activity_item → activity_session → venue`。

## 核心行为

- 推荐：结构化条件硬过滤后进行文本、时间、天气、偏好和多样性重排。
- 调整：通过 `SET / ADD / REMOVE / CLEAR` 修改状态；“换一批”复用查询条件并排除历史 ID。
- 澄清：城市等必要条件缺失时由 Java 规则决定追问，模型不直接控制状态。
- 规划：多时段候选由 Java 检索并验证活动 ID、场次 ID、重复活动及时间冲突。
- 数据源：PERSONAL 无候选时降级 PUBLIC；PUBLIC 严格查询无结果时生成待用户确认的 Relaxation 选项。
- 天气：仅作为软排序信号，不直接过滤户外活动。
